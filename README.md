# Personal Portfolio Website — Sourab Kumar

A clean, professional, and fully responsive personal portfolio website built using **pure HTML5 and CSS3** as part of the HTML & CSS Internship Project.

---

## 🚀 Project Overview
This portfolio website is designed to introduce Sourab Kumar, showcase technical skills and academic projects, and provide a clear way for visitors and potential employers to get in touch. It is built without any external frameworks or JavaScript, focusing strictly on foundational web development best practices.

---

## 📂 Features & Required Sections
- **Header & Navigation:** Sticky navigation bar with smooth scrolling anchors (`#home`, `#about`, `#skills`, `#projects`, `#contact`).
- **Hero / Home Section:** Professional introduction, role, and quick action buttons.
- **About Me Section:** Personal biography, education background, and career goals.
- **Technical Skills:** Displayed as clean styled tags (HTML5, CSS3, Flexbox & Grid, Responsive Design, Git & GitHub).
- **Featured Projects:** Project cards showcasing project titles, descriptions, and technologies used.
- **Contact Section:** Email, GitHub profile link, and a visual demo contact form.
- **Footer:** Copyright notice.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Flexbox, media queries for responsive mobile/desktop design, and interactive hover/focus states.
- **Tools:** Visual Studio Code, Git & GitHub.
